# CI implementation and verification

**Goal:** automate the existing repository checks, the next selected audit follow-up, in one task commit on main.
**Design:** one GitHub-hosted Ubuntu 24.04 job on PRs, main pushes and manual dispatch. Reuse npm scripts and the guarded disposable PostgreSQL Compose project. Read Node from .node-version and npm from packageManager; pin Python to the current sidecar patch (3.12.16). Use lockfile installs, SHA-pinned official Actions, Playwright's package-matched Chromium and read-only checkout permissions. Run frontend, backend, offline Python, all browser workflows and Docker deployment checks. Always clean up test PostgreSQL once startup has been attempted, and show its logs on failure. No application secrets, production data or live-provider qualification runs.
**Scope:** workflow configuration and documentation only. Do not add snapshot tests of YAML; validate the workflow with actionlint and execute its real checks. A matrix or multiple jobs would duplicate setup for this small suite, so keep one job.

- [x] Run the configured checks locally, including package-matched Chromium and Python 3.12.16 service tests, against disposable resources.
- [x] Independent review, document limits, commit on main. GitHub execution starts after the workflow is pushed; no push is requested.

Sources: [setup-node](https://github.com/actions/setup-node), [setup-python](https://github.com/actions/setup-python), [Playwright CI](https://playwright.dev/docs/ci), [actionlint](https://github.com/rhysd/actionlint).

## Verification

Actionlint 1.7.12 passes. Official Action release SHAs were verified with git ls-remote; Python 3.12.16 Ubuntu 24.04 x64 availability and Node 24.22.2 distribution availability were verified against official manifests. Fresh tracked checkout installs (npm ci at root and frontend) passed with Node 24.22.2/npm 11.19.1. Python 3.12.16 dependency consistency and all 16 offline market-service tests passed using the current sidecar image with networking disabled. Independent review found no blockers. The remaining check chain passed from the fresh tracked checkout using CI=true and package-matched Chromium: typecheck, 16 frontend tests, 20 backend unit tests, 215 integration tests, the original production browser workflow, yfinance trading workflow, 19 audit scenarios, 8 catalogue scenarios, and 5 Compose/nginx checks. This exercises the configured commands without relying on existing node_modules or a system Chrome path.


Validation limits: GitHub Actions itself has not run because this commit has not been pushed. Hosted checkout/setup/cache behavior, Ubuntu package installation and job timeout are validated statically against official documentation, not claimed as a hosted green result. Python tests ran in the current sidecar image at the same Python patch; other checks ran on the local host with fresh npm installs and Playwright's matching browser. Python transitive dependency locking remains a separate audit follow-up.

Application services/data and unrelated deferred provider research were untouched. The disposable test PostgreSQL instance was stopped and removed. No production app rebuild is needed for this workflow/documentation change.
